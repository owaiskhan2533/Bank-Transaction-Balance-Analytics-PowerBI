# Bank Transaction & Account Balance Analytics Dashboard

##  Executive Summary
This **Power BI Dashboard** provides deep insights into bank transaction flows, monthly account balance trends, and regional financial activity. It allows financial analysts to monitor account balances over time, evaluate transaction volumes across major cities (Bangalore, Delhi, Hyderabad, Mumbai), and analyze user behavior across different payment methods and devices[cite: 6, 7].

---

##  Tools & Technologies Used
* **Power BI Desktop:** Dynamic chart bookmarks (Line vs Column chart toggles), Matrix table visualisations, custom formatting[cite: 6, 7].
* **DAX & Data Modeling:** Aggregations for monthly balance tracking, remaining balances, and multi-currency transactions[cite: 6, 7].
* **Interactive Slicers:** Dynamic filtering by `BankNameSent`, `BankNameReceived`, `City`, `DeviceType`, `Gender`, `Age Groups`, `MerchantName`, `PaymentMethod`, `Purpose`, and `TransactionType`[cite: 6, 7].

---

##  Dashboard Pages & Visualizations

### 1. Monthly Balance & Account Trends
* **Monthly Balance Bar Chart:** Tracks average account balance month-by-month for 2024 (averaging around ~8.2M to 8.5M monthly balance)[cite: 6].
* **Dynamic Visual Toggle:** Buttons to switch seamlessly between:
  * Line Chart (Accounts)[cite: 6]
  * Column Chart (Accounts)[cite: 6]
  * Line Chart (Balance)[cite: 6]
  * Column Chart (Balance)[cite: 6]

### 2. City-Wise & Multi-Currency Breakdown
* **Regional Matrix Analysis:** Detailed breakdown of monthly transaction **Amount** and **Remaining Balance** segmented by major metropolitan hubs and currencies[cite: 7]:
  * **Bangalore:** Currency in **EUR**[cite: 7]
  * **Delhi:** Currency in **USD**[cite: 7]
  * **Hyderabad:** Currency in **GBP**[cite: 7]
  * **Mumbai:** Currency in **INR**[cite: 7]

##  Key Financial Insights
1. **Consistent Monthly Balances:** Monthly account balances remained stable throughout 2024, ranging between **8.2M and 8.5M**, peaking in June (~8.5M)[cite: 6].
2. **Regional Transaction Highlights:** High-value transactions are distributed across key tech hubs (Bangalore, Delhi, Hyderabad, Mumbai) using multiple currencies (EUR, USD, GBP, INR)[cite: 7].
3. **Flexible Exploration:** Comprehensive slicers enable immediate drill-down analysis into specific banks, payment methods, merchant categories, and demographic groups[cite: 6, 7].
